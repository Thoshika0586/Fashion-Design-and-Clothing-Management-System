Project Name : Fashion Design & Clothing Management System

Project Overview : 
The project is a Java-based Fashion Design and Clothing Management System developed using Object-Oriented Programming (OOP) principles. The 
system provides an integrated platform for customers, designers, and administrators to manage clothing designs, customer orders, payments,
deliveries, and inventory. It also includes a web-based frontend for user interaction and a Java backend that connects to a MySQL database 
through REST APIs.

System Features : 
The Fashion Design and Clothing Management System allows customers to register, log in, browse designs, add items to the cart, place orders, 
make payments. Designers can create and update clothing designs and manage customer orders. Administrators can manage
users, orders, inventory, and reports. The system also supports fabric management, payment processing, and bill generation using a Java
backend, a web-based frontend, and a MySQL database.

Technologies Used : 
The system is developed using Java as the primary programming language, following Object-Oriented Programming (OOP) principles. The user 
interface is built with HTML, CSS, and JavaScript, while the backend is implemented using Java REST APIs to handle business logic and 
communication with the database. MySQL is used for data storage and management. The project is developed in IntelliJ IDEA, and Git and GitHub 
are used for version control and collaborative development.

Project Structure :
The project is organized into three main parts: the backend, database, and frontend. The backend contains the Java source code, including 
models, database access classes, server files, and utility classes. The database folder stores the MySQL schema used to create the database. 
The frontend includes HTML pages, CSS, JavaScript, and other assets that provide the user interface. This structure keeps the project well 
organized and makes it easier to develop, maintain, and manage.
